# PA Politics — public releases

Sideloadable **debug** APKs for testing **PA Politics**, a Pennsylvania politics app.

The app source lives in a private repo. This repo exists so anyone with the link can download the APK **without GitHub authentication**.

## PA Politics V2.0 (beta)

**Direct download:**

https://github.com/sicpoe-wq/pa-politics-releases/releases/download/v2.0/PA-Politics-V2.0.apk

Also in-tree: [`release/PA-Politics-V2.0.apk`](./release/PA-Politics-V2.0.apk)

Previous version: [V1.0](https://github.com/sicpoe-wq/pa-politics-releases/releases/tag/v1.0)

### Install (Android)

1. Open the download link on your phone (or transfer the file).
2. Allow installs from that source (unknown apps / unknown sources).
3. Open the APK and install.
4. Launch **PA Politics**.

### Limits

- **Android only** (debug APK, Android 7.0+).
- Not Play Store–signed; phone must allow sideloading.
- **Not yet tested on a physical device or emulator.**
- Needs internet for maps, photos and live updates. Bundled data works offline.
- Unofficial. Confirm election details with the PA Department of State (vote.pa.gov).
